# Free AI Video Offline Prompt Kit

A working browser tool for creative brief JSON validation, prompt assembly, and Markdown export. All processing occurs in your browser. No model, API key, account, generation request, analytics, uploads, or private workflows.

Load an example for one of four image/video planning modes, edit the JSON, validate, then download JSON or Markdown. A reference name is a reminder, never an uploaded image. The app does not persist briefs: export before closing.

[Website](https://freeaivideo.art) · [Original library, CLI and tutorials](https://github.com/cydiz/freeaivideo-prompt-kit) · [npm](https://www.npmjs.com/package/freeaivideo-prompt-kit/v/0.1.1)

The offline tool is free under MIT. Website generation is a separate service requiring sign-in, credits and available providers. No model quality or unlimited free generation is promised. MIT covers only this independent tool, not the website's commercial template or model weights.
