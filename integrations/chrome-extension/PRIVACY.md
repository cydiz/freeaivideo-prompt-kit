# Privacy

This extension validates creative brief JSON in its popup and exports files only when you click a download button. It does not collect or transmit briefs, read the current webpage, access browser history, store briefs, call models, or run analytics. Import JSON reads only the local file you explicitly select. Website and source links open only when clicked; those external services have their own policies. Close the popup only after exporting if you need to retain your work. No host permissions or privileged Chrome APIs are requested.
